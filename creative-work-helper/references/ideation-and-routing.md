# Ideation and Routing

## Build territories before executions

Define 3–6 territories using genuinely different value or behavior mechanisms. Then create executions within promising territories.

Useful lenses include audience role, moment, context, emotion, narrative structure, participation, distribution, format, constraint inversion, combination, simplification, and scale shift.

## Diagnose weak ideation

- Same mechanism with different names: change the audience action or value exchange.
- Attractive style without strategic fit: return to desired audience change.
- Too safe: invert a category convention or remove a taken-for-granted constraint.
- Too broad: choose one moment, behavior, or tension.
- Too expensive: preserve the mechanism and redesign the production model.
- Assets do not support the concept: regroup the evidence or reframe the promise.

## Direction card

```text
Name
One-sentence concept
Core mechanism
Why it fits
Audience experience or action
Indicative form
Tradeoff / open question
```

Do not automatically merge every promising feature. Synthesis is useful only when mechanisms reinforce rather than dilute one another.

Before presenting directions, check whether they ask different things of the audience, create value through different mechanisms, and imply meaningfully different production or distribution models. If a different title or visual adjective is doing most of the differentiation, regenerate.
