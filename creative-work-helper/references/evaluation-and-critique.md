# Evaluation and Critique

## Adaptive evaluation

Choose criteria from the job. Possible dimensions include goal fit, audience value and comprehension, distinctiveness, evidence fit, feasibility, cost, time, platform fit, production complexity, scalability, repeatability, brand consistency, approval risk, rights, cultural risk, and measurability.

Never impose a universal priority order. Propose 3–5 Tentative priorities, explain why this work type suggests them, and let the user revise. Use qualitative comparison by default; use scores only if numerical contrast helps.

## Assumption register

For each important direction state:

- assumption;
- impact if false;
- confidence and evidence;
- cheapest useful test;
- decision that depends on it.

## Premortem

Imagine the work failed. Ask what was misunderstood, ignored, impossible to produce, rejected in approval, unsupported by assets, or unsustainable after launch. Convert each plausible failure into prevention, a validation step, or an accepted risk.

Critique the work, not the user. Separate fatal flaws, fixable weaknesses, tradeoffs, and taste preferences.
